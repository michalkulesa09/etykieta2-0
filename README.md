# Etykieta 2.0 — prototyp

To statyczna strona demonstracyjna. Otwórz `index.html` w przeglądarce, aby obejrzeć prototyp.

## Publikacja na GitHub Pages
1. Utwórz nowe publiczne repozytorium na GitHubie, np. `etykieta-2-0`.
2. Wybierz **Add file → Upload files** i wgraj `index.html`.
3. Wejdź w **Settings → Pages**.
4. W sekcji Build and deployment wybierz **Deploy from a branch**, gałąź `main`, folder `/(root)` i kliknij Save.
5. Po chwili strona będzie dostępna pod adresem `https://TWOJ_LOGIN.github.io/etykieta-2-0/`.

Wartości na stronie są przykładowe i wyraźnie oznaczone jako demonstracyjne. Przed wykorzystaniem poza prezentacją trzeba je zastąpić zweryfikowanymi danymi konkretnego produktu.
